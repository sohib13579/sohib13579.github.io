# التحيز والخصوصية والشفافية في الذكاء الاصطناعي — العرض التفاعلي

عرض ويب تفاعلي لمحتوى الورقة البحثية «التحيز والخصوصية والشفافية في الذكاء الاصطناعي —
دراسة تحليلية في ثلاثة تحديات أخلاقية وتقنية» (إعداد الطالب: صهيب مصطفى أحمد — نوفمبر 2026).

## التشغيل

- **الأسهل:** افتح `index.html` بالنقر المزدوج — الموقع يعمل كاملًا دون إنترنت
  (الخطوط العربية محمّلة محليًا داخل `fonts/`).
- إن لم تظهر الخطوط في متصفح شديد الصرامة، شغّل خادمًا محليًا بسيطًا وافتح
  `http://127.0.0.1:<PORT>/`، مثال: `python -m http.server 8000`.

## البنية

```
ai-ethics-site/
├── index.html        ← المحتوى الكامل (بنية دلالية + مكتبة أيقونات SVG داخلية)
├── css/
│   ├── fonts.css     ← تعريفات الخطوط المحلية (Noto Kufi / IBM Plex Sans Arabic / Amiri)
│   └── style.css     ← نظام التصميم (رموز → أساس → كروم → محاور → استجابة → حركة مخفّضة)
├── js/
│   └── main.js       ← كل التفاعلات (وحدات مرقّمة ومعلّقة)
└── fonts/            ← 20 ملف woff2 (عربي + لاتيني) للعمل دون اتصال
```

## العناصر التفاعلية (مرة واحدة لكل فكرة مهمة)

| الفكرة | التجربة |
|---|---|
| قصة COMPAS | عمودان متحركان 44.9% مقابل 23.5% |
| من أين يأتي التحيز؟ | أكورديون ثلاثي + أعمدة خوارزمية المستشفيات (17.7% → 46.5%) |
| تشبيه الكلمات | اختبار اختيار يكشف جواب النموذج «ربة منزل» |
| تعارض معايير العدالة | مبدّل «عدسة الشركة / عدسة الصحفيين» لبيانات COMPAS نفسها |
| إعادة تحديد الهوية (87%) | شبكة 100 نقطة تمتلئ بالتتابع |
| قصة نتفليكس | مخطط تقاطع البيانات بخط متحرك |
| تسريب GPT-2 | طرفية داكنة بكتابة آلية وتظليل البيانات الشخصية |
| الخصوصية التفاضلية | مؤشر تشويش + مبدّل «أقلية صغيرة» يُظهر دراسة Bagdasaryan |
| الصندوق الأسود | نموذج قرض تجريبي: قرار بلا سبب + تفسير LIME تقريبي بتحذير |
| بطاقات النماذج | بطاقة تنقلب كنشرة الدواء |
| التوتر بين الثلاثة | مثلث SVG بثلاثة خطوط توتر قابلة للنقر |
| العدّادات | 87% / 44.9% / 23.5% |

## ملاحظات

- كل الأرقام والشواهد منقولة من الورقة؛ صناديق «دراسة توضح الفكرة» تحمل رقم صفحتها في الورقة.
- قسم «المراجع والشواهد»: كل مرجع وشاهد يحمل رابطًا يفتح المصدر الأصلي في تبويب جديد (رابط المرجع = ناشر/نسخة المؤلف، وروابط الشواهد = المصدر الرسمي أو الموثوق لكل شاهد).
- «رأي الباحث» منفصل بصريًا عن المواد الموثقة (كتلة بخط أميري).
- يدعم `prefers-reduced-motion` (تعطيل الحركات لمن يفضّلها).
